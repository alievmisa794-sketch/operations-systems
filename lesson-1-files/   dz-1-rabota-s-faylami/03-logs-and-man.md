# Конспект: лог-файлы и справка man

Источник: слайды 36–39.

## Лог-файлы (каталог `/var/log/`)

| Файл | Содержимое |
|---|---|
| `/var/log/syslog` или `/var/log/messages` | Глобальный системный журнал (с момента запуска) |
| `/var/log/auth.log` или `/var/log/secure` | Авторизация пользователей: удачные и неудачные входы, задействованные механизмы аутентификации |
| `/var/log/dmesg` | Лог драйверов устройств |
| `/var/log/boot.log` | Лог загрузки ОС |
| `/var/log/cron` | Лог службы crond: выполняемые команды и их сообщения |
| `/var/log/faillog` | Неудачные попытки входа |
| `/var/log/kern.log` | Сообщения ядра |
| `/var/log/maillog` или `/var/log/mail.log` | Журнал почтового сервера |
| `/var/log/samba/` | Лог сервера Samba |
| `/var/log/yum.log` | Лог менеджера пакетов yum |
| `/var/log/mysql/` | Лог СУБД MySQL |
| `/var/log/httpd/` или `/var/log/apache2/` | Лог веб-сервера Apache: доступ — `access_log`, ошибки — `error_log` |

Просмотр логов:

```bash
less /var/log/maillog       # постраничный просмотр
tail -f /var/log/maillog    # следить за новыми записями в реальном времени
```

## Справка man

```bash
man tail    # справка по команде tail
man man     # справка по самой команде man
```

`man` открывает руководство по команде; прокрутка — стрелки / PgUp / PgDn, поиск — `/слово`, выход — `q`.

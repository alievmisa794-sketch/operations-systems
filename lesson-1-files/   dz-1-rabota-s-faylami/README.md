# Домашнее задание 3: Введение в GNU/Linux и виртуальные машины

## Цель работы
Изучить основы GNU/Linux, файловую структуру и работу с виртуальными машинами.

## Содержимое
- `ОС L (4).pptx` — презентация по теме

## Основные темы
- Проект GNU и ядро Linux
- Популярные дистрибутивы (Debian, Ubuntu, Arch, Red Hat)
- Файловая структура Linux и Inode
- Конфигурационные файлы (/etc)
- Лог-файлы (/var/log)
- Установка Oracle VM VirtualBox
- Снимки (snapshots) в виртуальной машине

## Вывод
Изучены основы операционной системы Linux и работа с виртуальными машинами.

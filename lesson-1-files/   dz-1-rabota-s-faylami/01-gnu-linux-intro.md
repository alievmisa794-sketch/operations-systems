# Конспект: Введение в GNU/Linux

Источник: слайды «ОС_L (4)» — «Введение в GNU/Linux».

## 1. Проект GNU (слайд 3)

- **The GNU Project** — проект по разработке свободного программного обеспечения (СПО), результат сотрудничества множества отдельных проектов.
- **Манифест GNU** (https://www.gnu.org/gnu/manifesto.html) написан Ричардом Столменом в 1985 году как призыв поддержать разработку операционной системы GNU. Часть текста взята из первоначального объявления 1983 года. До 1987 года манифест слегка обновлялся, с тех пор его решили оставить неизменным.
- **«GNU is Not Unix»** — цель проекта: разработать достаточно СПО, чтобы можно было обходиться без проприетарного ПО. Формально достигнута в 1992 году, одновременно с выпуском Linux.

## 2. Linux (слайды 4–5)

- **Linux — это ядро**: системная программа, которая выделяет ресурсы машины другим программам, запускаемым пользователем.
- Ядро — важная часть ОС, но само по себе бесполезно: работает только в составе полной операционной системы.
- Ядро Linux обычно применяют вместе с ОС GNU.
- **Дистрибутив Linux** = система GNU + ядро Linux, то есть **GNU/Linux**.

## 3. Дистрибутивы GNU/Linux (слайды 6–7)

**Дистрибутив** — общее название ОС на ядре Linux, готовых к установке на пользовательское оборудование.

Состав дистрибутива:

1. ядро Linux;
2. библиотеки и утилиты проекта GNU;
3. графическая подсистема X Window System (Wayland);
4. графическое окружение рабочего стола;
5. документация;
6. набор приложений (редакторы документов и таблиц, медиаплееры, СУБД и т. д.).

В дистрибутив могут входить программы с собственническими лицензиями (драйверы, кодеки).

Общие сведения:

- Существует более 600 дистрибутивов, больше половины из них поддерживаются в актуальном состоянии (регулярные обновления).
- С коммерческой поддержкой: Red Hat / Fedora, openSUSE, Ubuntu. Силами добровольцев: Debian, Slackware, Gentoo, Arch Linux.
- У многих дистрибутивов есть установщик. Gentoo и Arch Linux содержат только ядро, средства сборки ПО и установщик, который собирает нужное ПО под архитектуру устройства.
- Каталог дистрибутивов: https://distrowatch.com/

## 6. Файловая структура: каталоги и inode (слайды 22–25)

Схема иерархии каталогов — см. [`images/linux-directory-hierarchy.png`](../images/linux-directory-hierarchy.png).

**Inode (индексный дескриптор)** хранит метаданные о файлах, каталогах и других объектах файловой системы.

- Цепочка: **имя файла (папки) → inode → физические данные**.
- Любой файл в каталоге имеет имя и номер inode; по номеру inode можно узнать метаданные.
- Номера inode уникальны **в пределах раздела**: на разных разделах могут быть файлы с одинаковым номером.
- Количество inode определяется при создании файловой системы.

Типичные атрибуты inode:

- размер;
- владелец;
- дата/время;
- разрешения и контроль доступа;
- расположение на диске;
- тип файла;
- количество ссылок;
- дополнительные метаданные.

Полезные команды: `ls -i` (показать номера inode), `stat файл` (метаданные), `df -i` (использование inode).

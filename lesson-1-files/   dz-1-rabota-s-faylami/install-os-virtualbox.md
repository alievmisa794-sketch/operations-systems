# Инструкция: создание виртуальной машины и установка ОС (Oracle VirtualBox)

В примере используется **Ubuntu Desktop (LTS)**; для других дистрибутивов шаги те же.

## 1. Подготовка

1. Включите виртуализацию (Intel VT-x / AMD-V) в BIOS/UEFI, если она выключена.
2. Скачайте и установите **Oracle VirtualBox** с https://www.virtualbox.org/ (для вашей ОС) и запустите установщик с настройками по умолчанию.
3. Скачайте ISO-образ дистрибутива, например с https://ubuntu.com/download/desktop.
4. Свободного места: не менее 25–30 ГБ на диске, ОЗУ: желательно от 8 ГБ на хосте.

## 2. Создание виртуальной машины

1. В VirtualBox нажмите **Создать (New)**.
2. **Имя:** `ubuntu-lab`; **Образ ISO:** выберите скачанный файл. Тип и версия (Linux / Ubuntu 64-bit) определятся автоматически. Если есть опция *Skip Unattended Installation*, отметьте её, чтобы пройти установщик вручную.
3. **Оборудование:** ОЗУ 4096 МБ, процессоры 2.
4. **Жёсткий диск:** создать новый виртуальный диск, 25 ГБ, тип VDI, динамический.
5. Нажмите **Готово**.
6. Перед запуском: **Настройки → Система → Процессор** (2 CPU), **Дисплей** → видеопамять 128 МБ, **Сеть** → NAT (по умолчанию).

## 3. Установка ОС

1. Нажмите **Запустить (Start)** — ВМ загрузится с ISO.
2. Выберите **Try or Install Ubuntu → Install Ubuntu**.
3. Язык и раскладка клавиатуры → *Normal installation* → отметьте установку обновлений и стороннего ПО (по желанию).
4. Тип установки: **Erase disk and install Ubuntu** (это затронет только виртуальный диск, а не ваш реальный).
5. Часовой пояс, имя пользователя, имя компьютера, пароль.
6. Дождитесь завершения и нажмите **Restart now**. Когда попросит, извлеките установочный носитель (Enter).
7. Войдите в систему под созданным пользователем.

## 4. Настройка после установки

```bash
sudo apt update && sudo apt upgrade -y
sudo apt install -y build-essential dkms linux-headers-$(uname -r)
```

Дополнения гостевой ОС (Guest Additions): меню **Устройства → Подключить образ диска Дополнений гостевой ОС**, затем:

```bash
cd /media/$USER/VBox_GAs_*
sudo ./VBoxLinuxAdditions.run
sudo reboot
```

После этого работают общий буфер обмена, автоматическое разрешение экрана и общие папки.

## 5. Проверка

```bash
cat /etc/os-release
uname -r
df -h
```

Сделайте снимки экрана (скриншоты) для отчёта и положите их в `images/`.

> Рекомендация: после установки и настройки сразу сделайте **снимок** «Чистая установка» — см. [snapshots.md](snapshots.md).

## 6. Частые проблемы

| Проблема | Решение |
|---|---|
| В списке версий нет 64-битных ОС | Включите виртуализацию в BIOS; на Windows отключите Hyper-V / Hyper-V-платформу, если мешает |
| ВМ «тормозит» | Увеличьте ОЗУ/видеопамять, включите 3D-ускорение, установите Guest Additions |
| Нет интернета | Сеть → NAT; перезапустите ВМ |
| Установщик не видит диск | Проверьте, что виртуальный диск создан и подключён к контроллеру SATA |

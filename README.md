## Часть 1. Конспект по материалам лекции

### 1. Проект GNU и ядро Linux
- **Проект GNU** (GNU is Not Unix) — проект по разработке свободного программного обеспечения, инициированный Ричардом Столлменом в 1985 году с целью создания ОС, свободной от проприетарного ПО.
- **Linux** — это ядро, системная программа, которая управляет ресурсами машины и выделяет их другим программам. Само по себе ядро бесполезно без пользовательского окружения.
- **GNU/Linux** — полное название операционной системы, состоящей из ядра Linux и набора утилит/библиотек проекта GNU.

### 2. Популярные дистрибутивы GNU/Linux
- **Debian**: Один из старейших и самых стабильных дистрибутивов. Обновления выходят редко (раз в ~2 года).
- **Ubuntu**: Самый популярный дистрибутив, основан на Debian. Разрабатывается компанией Canonical, обновления каждые 6 месяцев.
- **Linux Mint**: Основан на Ubuntu, ориентирован на новичков, имеет интерфейс (Cinnamon), похожий на Windows.
- **Arch Linux / Manjaro**: Дистрибутивы с моделью обновления Rolling Release (постоянные обновления). Arch предоставляет минималистичную базу, Manjaro делает её более дружелюбной.
- **Семейство Red Hat**: RHEL (коммерческий), Fedora (тестовый полигон для RHEL), CentOS (бесплатная стабильная версия).

### 3. Файловая структура и Inode
- Файловая система Linux иерархична, начинается с корневого каталога `/`.
- **Inode (индексный дескриптор)**: Уникальный идентификатор файла в пределах раздела. Хранит метаданные: размер, владельца, права доступа, время создания/изменения, тип файла и расположение данных на диске. Имя файла не хранится в inode, оно хранится в каталоге и ссылается на номер inode.

### 4. Основные конфигурационные файлы (каталог `/etc`)
- `/etc/hostname` — имя хоста.
- `/etc/passwd` — список пользователей.
- `/etc/group` — группы пользователей.
- `/etc/shadow` — хэши паролей пользователей.
- `/etc/sudoers` — настройка привилегий команды `sudo`.
- `/etc/fstab` — таблица монтирования файловых систем.
- `/etc/resolv.conf` — настройки DNS.
- `/etc/hosts` — локальные псевдонимы для сетевых узлов.

### 5. Лог-файлы (каталог `/var/log`)
- `/var/log/syslog` или `/var/log/messages` — глобальный системный журнал.
- `/var/log/auth.log` или `/var/log/secure` — логи авторизации (удачные и неудачные входы).
- `/var/log/dmesg` — сообщения от драйверов устройств.
- `/var/log/boot.log` — лог загрузки ОС.
- Для просмотра логов используются команды `less` (постраничный просмотр) и `tail -f` (отслеживание в реальном времени).

## Часть 2. Инструкция по установке Oracle VM VirtualBox и созданию ОС

### Шаг 1: Установка гипервизора
1. Перейдите на официальный сайт [VirtualBox](https://www.virtualbox.org/wiki/Downloads).
2. Скачайте установочный файл для вашей хост-операционной системы (Windows/macOS).
3. Запустите установщик и следуйте инструкциям мастера установки (настройки по умолчанию).

### Шаг 2: Скачивание образа ОС
1. Перейдите на сайт выбранного дистрибутива (например, [Ubuntu](https://ubuntu.com/download/desktop)).
2. Скачайте ISO-образ операционной системы (рекомендуется версия LTS, например, 22.04 или 24.04).

### Шаг 3: Создание виртуальной машины
1. Откройте VirtualBox и нажмите кнопку **«Создать»** (New).
2. **Имя**: Введите имя (например, `Ubuntu-Linux`). Тип: `Linux`, Версия: `Ubuntu (64-bit)`.
3. **Размер оперативной памяти**: Выделите не менее 2048 МБ (2 ГБ), рекомендуется 4096 МБ (4 ГБ).
4. **Виртуальный жёсткий диск**: Выберите «Создать новый виртуальный жёсткий диск», тип `VDI`, динамический, размером не менее 20–25 ГБ.
5. Нажмите **«Создать»**.

### Шаг 4: Установка операционной системы
1. Выберите созданную виртуальную машину и нажмите **«Настроить»** (Settings).
2. Перейдите в раздел **«Носители»** (Storage).
3. В контроллере IDE нажмите на значок пустого диска и выберите **«Выбрать файл диска...»**. Укажите скачанный ранее ISO-образ Ubuntu.
4. Нажмите «ОК» и запустите виртуальную машину кнопкой **«Запустить»** (Start).
5. Следуйте инструкциям установщика Ubuntu: выберите язык, раскладку клавиатуры, нажмите «Установить Ubuntu», выберите «Стереть диск и установить Ubuntu» (это безопасно, так как стирается только виртуальный диск), создайте пользователя и пароль, дождитесь окончания установки и перезагрузите машину.

## Часть 3. Иерархия папок в Linux

В Linux всё является файлом, а файловая система представляет собой единое дерево, начинающееся с корневого каталога `/`.

```text
/               ← Корневой каталог (начало всей файловой системы)
├── bin/        ← Основные исполняемые файлы (команды) для всех пользователей
├── boot/       ← Файлы, необходимые для загрузки системы (ядро, initrd)
├── dev/        ← Файлы устройств (диски, терминалы и т.д.)
├── etc/        ← Конфигурационные файлы системы и установленных программ
├── home/       ← Домашние каталоги обычных пользователей (/home/user)
├── lib/        ← Системные библиотеки, необходимые для работы программ
├── media/      ← Точки монтирования для съёмных носителей (флешки, CD)
├── opt/        ← Дополнительное программное обеспечение от сторонних разработчиков
├── proc/       ← Виртуальная файловая система с информацией о процессах и ядре
├── root/       ← Домашний каталог суперпользователя (root)
├── sbin/       ← Исполняемые файлы для системного администрирования
├── tmp/        ← Временные файлы (очищаются при перезагрузке)
├── usr/        ← Пользовательские программы, документация, исходные коды
└── var/        ← Переменные данные: логи (/var/log), кэш, базы данных, очереди печати

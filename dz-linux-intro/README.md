## Часть 1. Конспект по слайдам лекции

### 1. Проект GNU и ядро Linux
- **Проект GNU** (GNU is Not Unix) — проект по разработке свободного программного обеспечения. Манифест GNU написан Ричардом Столлменом в 1985 году с целью «разработки достаточного количества СПО, чтобы было возможно обходиться без проприетарного ПО».
- **Linux** — это ядро, системная программа, которая выделяет ресурсы машины другим программам. Само по себе ядро бесполезно и функционирует только в составе полной ОС.
- **GNU/Linux (Дистрибутив)** — операционная система, состоящая из ядра Linux, набора библиотек и утилит проекта GNU, графической подсистемы (X Window System / Wayland) и набора приложений.

### 2. Популярные дистрибутивы GNU/Linux
- **Debian**: Один из старейших и самых стабильных дистрибутивов (первый выпуск в 1993 г.). Обновления выходят примерно раз в 2 года.
- **Ubuntu**: Самый популярный дистрибутив, основан на Debian. Разрабатывается компанией Canonical, обновления выходят 2 раза в год.
- **Linux Mint**: Основан на Ubuntu, ориентирован на новичков. Интерфейс Cinnamon схож с Windows.
- **Arch Linux**: Минималистичная базовая система, обновляется по модели Rolling Release. Пользователь сам собирает нужное ПО (доступ к AUR).
- **Manjaro**: Построен на базе Arch Linux, но более дружелюбен к пользователю, имеет высокую стабильность.
- **Семейство Red Hat**: 
  - *RHEL* (Red Hat Enterprise Linux) — коммерческий, с высокой стабильностью и поддержкой.
  - *Fedora* — свободный дистрибутив, «тестовый полигон» для RHEL.
  - *CentOS* — бесплатная стабильная версия RHEL (CentOS Stream).
- **openSUSE**: Основан на Slackware, обновляется раз в год, подходит для бизнеса и дома.

### 3. Файловая структура и Inode
- Файловая система Linux иерархична.
- **Inode (индексный дескриптор)**: предназначен для хранения метаданных о файлах и каталогах. Имя файла ссылается на номер inode. Inode уникален в пределах одного раздела и хранит: размер, владельца, дату/время, разрешения (права доступа), расположение на диске, тип файла и количество ссылок.

### 4. Основные конфигурационные файлы (каталог `/etc`)
- `/etc/hostname` — имя хоста.
- `/etc/sysconfig/` — каталог с файлами конфигурации системы.
- `/etc/ssh/` и `$HOME/.ssh/config` — конфигурация сервера и клиента SSH.
- `/etc/resolv.conf` — настройки DNS.
- `/etc/hosts` — псевдонимы для сетевых узлов.
- `/etc/os-release` — версия и название дистрибутива.
- `/etc/passwd` — список пользователей.
- `/etc/group` — группы пользователей.
- `/etc/shadow` — хэши паролей пользователей.
- `/etc/sudoers` — конфигурация привилегий команды `sudo`.
- `/etc/environment` — переменные окружения (PATH).
- `/etc/fstab` — хранит записи для монтирования файловых систем.
- `/etc/default/grub` — конфигурация для создания `grub.cfg`.
- `/etc/crontab` — конфигурация планировщика заданий.

### 5. Лог-файлы (каталог `/var/log`)
- `/var/log/syslog` (или `/var/log/messages`) — глобальный системный журнал.
- `/var/log/auth.log` (или `/var/log/secure`) — информация об авторизации (удачные и неудачные попытки входа).
- `/var/log/dmesg` — лог драйверов устройств.
- `/var/log/boot.log` — лог загрузки операционной системы.
- `/var/log/cron` — лог службы crond.
- Для просмотра используются команды `less` (постраничный просмотр) и `tail -f` (отслеживание в реальном времени).

## Часть 2. Инструкция по установке Oracle VM VirtualBox и созданию ОС

1. **Скачивание ПО**: Перейдите на официальный сайт [virtualbox.org](https://www.virtualbox.org/) и скачайте установщик для вашей ОС (Windows/macOS). Также скачайте ISO-образ дистрибутива Linux (например, Ubuntu LTS).
2. **Создание виртуальной машины (ВМ)**:
   - Откройте VirtualBox и нажмите **«Создать»**.
   - Введите имя (например, `Ubuntu`), выберите Тип: `Linux`, Версия: `Ubuntu (64-bit)`.
   - Выделите оперативную память (рекомендуется не менее 2048–4096 МБ).
   - Создайте новый виртуальный жёсткий диск (тип VDI, динамический, размер 20–25 ГБ).
3. **Настройка и установка**:
   - Выберите созданную ВМ, нажмите **«Настроить»** → раздел **«Носители»**.
   - В контроллере IDE нажмите на значок диска и выберите **«Выбрать файл диска...»**, указав скачанный ISO-образ.
   - Нажмите **«Запустить»**. Следуйте инструкциям установщика Ubuntu (выбор языка, раскладки, разметка диска «Стереть диск и установить Ubuntu», создание пользователя и пароля).

## Часть 3. Иерархия папок в Linux

Файловая система представляет собой единое дерево, начинающееся с корневого каталога `/`:

```text
/               ← Корневой каталог (начало всей файловой системы)
├── bin/        ← Основные исполняемые файлы (команды) для всех пользователей
├── boot/       ← Файлы, необходимые для загрузки системы (ядро, initrd)
├── dev/        ← Файлы устройств (диски, терминалы и т.д.)
├── etc/        ← Конфигурационные файлы системы и установленных программ
├── home/       ← Домашние каталоги обычных пользователей (/home/имя_пользователя)
├── lib/        ← Системные библиотеки, необходимые для работы программ
── media/      ← Точки монтирования для съёмных носителей (флешки, CD)
├── opt/        ← Дополнительное программное обеспечение от сторонних разработчиков
├── proc/       ← Виртуальная файловая система с информацией о процессах и ядре
├── root/       ← Домашний каталог суперпользователя (root)
├── sbin/       ← Исполняемые файлы для системного администрирования
├── tmp/        ← Временные файлы (очищаются при перезагрузке)
├── usr/        ← Пользовательские программы, документация, исходные коды
└── var/        ← Переменные данные: логи (/var/log), кэш, базы данных

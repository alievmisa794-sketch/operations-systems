# Домашнее задание: урок 9. Управление памятью в Linux

## Цель работы
Изучить механизмы управления памятью в ОС Linux. Открыть системные файлы виртуальной файловой системы `/proc`, описанные в презентации «Память», проанализировать их содержимое и продемонстрировать работу с картами и страницами памяти для нескольких различных процессов.

---

## Краткая теоретическая справка
Согласно материалам лекции, операционная система управляет оперативной памятью, контролируя доступ к адресным пространствам процессов и защищая выделенные области от взаимного вмешательства. Виртуальная файловая система `/proc` предоставляет интерфейс к структурам данных ядра, позволяя просматривать информацию о физической и виртуальной памяти, а также о распределении ресурсов между процессами.

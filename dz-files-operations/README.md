## 1. Типы файлов в Linux

| Тип | Обозначение | Описание |
|-----|-------------|----------|
| Обычный файл | `-` | Текстовые файлы, исполняемые файлы (программы), файлы ввода/вывода |
| Каталог | `d` | Списки других файлов |
| Ссылка | `l` | Механизм видимости файла в разных частях файлового дерева |
| Сокет | `s` | Взаимодействие процессов в сети (аналог TCP/IP сокетов) |
| Именованный канал FIFO | `p` | Коммуникация между процессами без сетевых сокетов |
